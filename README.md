# 🎟️ Issue Tracker

Цялостно уеб приложение за управление на задачи (билети) и проследяване на техния статус. Проектът е разделен на клиентска (Frontend) и сървърна (Backend) част, предлагайки интерактивен интерфейс и сигурна работа с база данни.

---

## Основни функционалности

* **Управление на задачи:** Създаване, преглед, редакция и изтриване на задачи.
* **Детайлен изглед (Ticket View):** Интерактивна страница за всеки билет с възможност за смяна на статус, приоритет и изпълнител.
* **Строг Workflow:** Локална и сървърна валидация при преминаване между различните статуси (напр. от "To Do" в "In Progress").
* **Комуникация:** Възможност за добавяне на коментари към задачите.
* **Системни логове:** Автоматично генериране на системни записи при промяна на ключови полета (статус, приоритет, изпълнител).
* **Известия (Notifications):** Система за уведомяване на потребителите при промени по техните задачи.
* **Автентикация:** Защита на данните чрез JWT (JSON Web Tokens).

## Инсталация и стартиране локално

Проектът е конфигуриран за бързо локално стартиране **без нужда от допълнителни `.env` конфигурации**. За да го стартирате, ще ви трябват два отделни терминала.

### 1. Стартиране на Backend сървъра
Отворете първия терминал и навигирайте до папката `backend`:

```bash
cd backend
npm install
npm run dev
